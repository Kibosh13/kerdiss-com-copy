# Kerdiss — русская копия сайта

Демонстрация: https://kibosh13.github.io/kerdiss-com-copy/

Публичная часть https://kerdiss.com/ сохранена 11 сентября 2026 года. Содержит 33 страницы, 3 перенаправления, 8 карточек товаров, 2 категории каталога, оригинальные изображения, шрифты, CSS и JavaScript. Русские тексты встроены в HTML. Переключатель языков удалён. Сохранены адаптивная вёрстка, меню, галереи и сортировка каталога.

## Структура

- `site/` — редактируемые исходные статические файлы. Это основное содержимое проекта, а не временный результат сборки.
- `scripts/build_pages.py` — экспорт для GitHub Pages с префиксом `/kerdiss-com-copy/` и обязательным `noindex` на всех HTML-страницах.
- `scripts/publish_pages.py` — обновление демонстрационной ветки обычным Git-коммитом без принудительной перезаписи истории и без архивов.
- `main` — исходники и инструкции.
- `gh-pages` — опубликованная статическая демонстрация, корень ветки, `.nojekyll`.

Зависимости: Python 3.9+ и Git; Node.js, PHP и база данных для статического просмотра не требуются.

## Локальный просмотр

Из корня проекта:

```sh
python3 -m http.server 8080 --directory site
```

Откройте http://localhost:8080/. Для экспорта GitHub Pages:

```sh
python3 scripts/build_pages.py
```

Результат создаётся в игнорируемой папке `.build/pages/`. Для другого хостинга можно задать `--base / --origin https://example.com`; запрет индексации сохраняется.

## Обновление

Редактируйте файлы в `site/`, проверьте результат локально, затем отправьте обычный коммит в `main`. После этого:

```sh
python3 scripts/publish_pages.py
```

Скрипт требует чистую ветку `main`, получает актуальную `gh-pages`, создаёт коммит только при изменении файлов и отправляет его без `--force`. При конфликте с параллельным обновлением push останавливается: сначала проверьте чужие изменения. GitHub Pages автоматически публикует новую версию из `gh-pages`. Локальные зависимости, кэши, архивы, базы, `.env`, логи и сборка исключены через `.gitignore`.

## Возможности статической версии

Восстановлена публичная часть сайта. Исходный WordPress, PHP, база, админка, учётные записи, история заказов и заявок недоступны через публичные страницы и **не восстановлены**. Их нет и в `main`.

- Формы заявок, отзывов, авторизация, бронирование, оформление заказов и обработка платежей требуют серверной части. Статические формы не отправляют данные и показывают сообщение с опубликованными контактами.
- Поиск WordPress и серверные фильтры не реализованы. Каталог и сохранённая сортировка работают локально.
- На странице контактов встроена Google Maps с поиском нового юридического адреса в Москве. Старый виджет с неработающим API-ключом удалён.
- Poptin отключён; его удалённая обработка и аналитика не подключены. Ссылки WhatsApp и Facebook оставлены как обычные внешние ссылки.
- Сохранённые публичные служебные токены и nonce WordPress очищены. Секреты GitHub не записываются в проект.

## Индексация

Экспорт всегда добавляет `noindex, nofollow, noarchive` во все HTML, включая перенаправления и страницу 404. Карты сайта не публикуются. `robots.txt` содержит `Disallow: /`; основной механизм запрета для проекта GitHub Pages — метатег каждой страницы, поскольку robots.txt применяется только из корня домена. Публичность репозитория и запрет поисковой индексации — разные настройки.

## Настройки после сохранения

По указанию владельца установлен логотип URSAR из предоставленного PDF, обновлены юридический адрес, телефоны и почта. WhatsApp ведёт на мобильный номер +7 926 757 79 79. Боковая форма закрыта при загрузке каждой страницы и открывается по нажатию. Название категории — «Газонокосилки».

## Точность сохранения

Используются оригинальная разметка и ресурсы. При первичной проверке главной, About, Product Show, Shop, Services и Contact сравнивались русские тексты, шрифты, геометрия заголовков и высота страницы при ширине 1280 px. Мобильная версия проверялась при 390 px; проверены меню, каталог, сортировка и галерея. Абсолютное совпадение каждого пикселя на всех устройствах не заявляется: отображение зависит от браузера и внешних сервисов. Языковой переключатель удалён по заданию.
